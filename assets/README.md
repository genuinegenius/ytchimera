# Assets Directory

This directory should contain the following image assets:

## Required Assets

1. **icon.png** (1024x1024)
   - Main app icon
   - Square format
   - Background: #0C090A (dark background)
   - Foreground: YTB Chimera logo/branding

2. **splash-icon.png** (1284x2778 or similar)
   - Splash screen image
   - Can be the same as icon.png
   - Background: #0C090A

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon foreground
   - Transparent background or same as icon.png

4. **favicon.png** (48x48 or 64x64)
   - Web favicon
   - Can be a smaller version of icon.png

## Notes

- All icons should maintain consistent branding
- Use the app's primary color (#0A84FF) and dark background (#0C090A)
- Ensure icons are high quality and look good at various sizes
- For production, consider using a professional designer or icon generator

## Temporary Placeholders

For development purposes, you can use simple placeholder images or the default Expo icons until you create proper branded assets.
